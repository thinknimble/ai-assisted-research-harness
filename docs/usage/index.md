# Usage

Research Assistant runs in two modes. Pick the one that matches what you want to do:

| Mode | What it does | When to use it |
|---|---|---|
| **[Reception](reception-mode.md)** | Answers your questions using the document library | You want to find information or ask questions |
| **[Backoffice](backoffice-mode.md)** | Processes new documents and files them in the library | You've added a new document and want it indexed |

## Switching between modes

You choose the mode when you start the tool. To switch modes, exit the current session (`quit`) and start a new one with the other mode.

## Other commands

| Command | What it does |
|---|---|
| `research-assistant init <folder>` | [Set up a new research library](../getting-started/installation.md) |
| `research-assistant repos` | [List all your registered libraries](managing-repos.md) |
