# Documentation Reflects Write Tools

The user-facing docs describe reception's ability to write output files and the new `output/` directory.

## Success Criteria

- **`docs/index.md`**: The "How it works" table includes a row for `output/` — "Files generated by reception mode (summaries, exports, spreadsheets)"
- **`docs/getting-started/installation.md`**: The init output listing and "What init creates" admonition include `output/`. The description reads something like "where reception saves generated files"
- **`docs/usage/reception-mode.md`**: A new "Writing output files" section appears after "Asking questions". It covers:
  - Text file output (`.md`, `.csv`, `.json`, `.txt`) with an example conversation showing a user asking for a summary and the assistant writing it to a file
  - Spreadsheet output (`.xlsx`) with an example showing tabular data export
  - Where output files are saved (`output/` directory)
  - The new status messages (`[using write_text_file: ...]`, `[using write_spreadsheet: ...]`) are added to the status message table
- **`docs/usage/reception-mode.md`**: The "What it can do" list includes "Export research as markdown summaries, CSV data, or Excel spreadsheets"
- **`docs/faq.md`**: A new "Output files" section under Reception mode with entries:
  - "What file formats can the assistant write?" — lists `.md`, `.csv`, `.json`, `.txt`, `.xlsx`
  - "Where do output files go?" — explains the `output/` directory
